## Allowed Modules (5 total)
1. Dashboard — KPIs e visão geral
2. Matriz de Proteção — Tabela completa de falhas com filtros
3. Sistemas WTG — Referência técnica dos 7 subsistemas (Conversor, Pitch, Yaw, Hidráulico, Drivetrain/Gerador, Controle Principal, Estação MT)
4. Componentes Elétricos — Guia de componentes elétricos comuns no WTG
5. Comissionamento — Checklists de comissionamento off-grid/on-grid

## Removed Modules — DO NOT re-add
- Subsistemas (removed — confusing, replaced by Sistemas WTG)
- Interligações (removed — not needed)
