# Wind Turbine Guardian

Crie um sistema web completo de Matriz de Proteção dos WTGs das turbinas Eolicas de Serra da Palmeira - Modelo somente: GWH171 - V11 R01C100 6.0MW. projeto de uma forma profissional. Ação: Especificação de todos os atuadores que compõem o WTG, detalhando lógicas de falhas com possíveis 3 ações de correção e o que ocasiona com a falha no sistema do wtg: exemplo do sistam: salesforce.com , funcionamento e interligações com os demais componentes: Dashboard.
